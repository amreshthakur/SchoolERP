# School ERP — Offline Desktop Application

A production-shaped, offline-first school ERP built with Electron, Node.js, and SQLite.
Runs entirely on a single Windows computer (later: LAN multi-PC).

## Requirements

- Node.js 18+ (LTS recommended)
- Windows 10/11 for building the installer (dev works on macOS/Linux too)

## Install & Run (development)

```bash
npm install
npm start
